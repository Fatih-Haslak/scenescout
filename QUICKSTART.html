Başlangıç rehberi · Windows 10 / 11, x64

Hatırladığın sahneyi bul.

Video ekle, sahneyi tarif et, sonucu aç. Görüntüler bilgisayarında işlenir. Python, komut satırı veya API anahtarı bilgisi gerekmez.

  1. Kur: GitHub sürümündeki SceneScout-Setup-Windows-x64.exe dosyasını aç. Türkçe dilini seç, kurulumu tamamla. Yönetici izni gerekmez.
  2. Başlat: Masaüstündeki SceneScout kısayoluna çift tıkla. Python ve gerekli paketler otomatik hazırlanır. İlk açılışta internet gerekir; indirme sürerken pencereyi açık tut.
  3. Video ekle: Açılan tarayıcıda dosya yükle veya herkese açık YouTube / X video bağlantısı yapıştır. İlk video için yaklaşık 1,5 GB model indirilir. İlerlemeyi izle ve Hazır yazmasını bekle.
  4. Sahneyi ara: “Çimenlerde oturan bir tavşan” gibi gördüğün şeyi yaz. Sonuca tıklayınca video o ana gider. Referans görsel de kullanabilirsin.

Kurulum dosyasının bitmesi, modelin de indirildiği anlamına gelmez. İlk açılış ortamı hazırlar; ilk video modeli indirir. Sonraki kullanımlar önbelleği kullanır. Diskte birkaç GB boş alan bırak. CPU çalışır, ancak ilk indeksleme daha yavaştır.

Günlük kullanım

Uygulamayı kullanırken açılış penceresini açık tut. Durdurmak için o pencerede Ctrl+C kullan. Tarayıcı sekmesini kapatmak sunucuyu durdurmaz.

NVIDIA GPU ve uyumlu sürücün varsa Başlat menüsündeki SceneScout - NVIDIA GPU seçeneğini kullanabilirsin. Ek paketler indirir; CPU ve GPU ortamları ayrıdır.

Açılmıyor veya indirme yarım kaldı

İnternet bağlantısını ve boş alanı kontrol et, kısayolu yeniden aç. Son hata ve kurulum kaydı %LOCALAPPDATA%\SceneScout\Logs\setup-cpu.log dosyasındadır. GPU açılışında dosya setup-cuda.log olur. Sorun bildirirken kişisel yolları ve video adreslerini kayıttan çıkart.

Tarayıcı kendiliğinden açılmazsa 127.0.0.1:8765 adresini aç. Bu adres yalnızca uygulama çalışırken kullanılabilir.

Videolarım nerede? Nasıl güncellerim?

Kurulum dosyaları %LOCALAPPDATA%\Programs\SceneScout; video kopyaları ve indeksler %LOCALAPPDATA%\SceneScout\Data klasöründedir. Güncellemeden önce uygulamayı Ctrl+C ile durdur, yeni kurulum dosyasını çalıştır. Video arşivi korunur. Windows Ayarlar → Uygulamalar üzerinden kaldırınca da veriler tutulur. Kalıcı silmek istersen önce yedekle, sonra veri klasörünü kendin sil.

ZIP kullanıyorsan önce çıkart ve Start.cmd dosyasını aç. ZIP arşivi kendi .data klasörünü kullanır; yükseltirken bu klasörü yeni klasöre kopyala. Eski ZIP arşivi otomatik taşınmaz.

Bağlantı çalışmıyor veya arama sonucu zayıf

Tekil, herkese açık YouTube/Shorts ve X videoları desteklenir. Giriş isteyen, özel, canlı veya platformun engellediği içerikler indirilemeyebilir. Elindeki video dosyasını yükleyebilirsin.

Görünen nesneleri ve ortamı tarif et. Bu sürüm konuşmayı dinlemez ve özet üretmez. Benzerlik puanı doğruluk yüzdesi değildir. Çok yüksek filtre doğru sonuçları da gizleyebilir.

Getting started · Windows 10 / 11, x64

Find the moment you remember.

Add a video, describe a scene, open the result. Images are processed locally. No Python knowledge or API key is required.

  1. Install: Open SceneScout-Setup-Windows-x64.exe from the GitHub release. Choose English and finish the wizard. No administrator access is needed.
  2. Launch: Double-click the SceneScout desktop shortcut. Python and dependencies are prepared automatically. The first launch needs internet; keep the launch window open.
  3. Add a video: Upload a file or paste a public YouTube / X video link. The first video downloads approximately 1.5 GB of model weights. Wait for Ready.
  4. Search: Try “A rabbit sitting in the grass”. Click a result to jump to that moment. You can also search with a reference image.

The installer copies the app. The first launch prepares its environment. The first video downloads the model. Later launches reuse cached files. Leave several GB of free space. CPU works; initial indexing takes longer.

Everyday use

Keep the launch window open while using the app. Stop with Ctrl+C in that window. Closing the browser tab does not stop the server.

On a compatible NVIDIA GPU/driver, use SceneScout - NVIDIA GPU in the Start menu. It downloads extra packages into a separate environment.

Startup or download failed

Check internet access and disk space, then launch again. Setup logs: %LOCALAPPDATA%\SceneScout\Logs\setup-cpu.log or setup-cuda.log. Remove personal paths and video URLs before sharing a log.

If the browser does not open, visit 127.0.0.1:8765 while the app is running.

Updates, data and uninstall

App files: %LOCALAPPDATA%\Programs\SceneScout. Video copies and indexes: %LOCALAPPDATA%\SceneScout\Data. Stop the app with Ctrl+C before running a newer installer. Updates and uninstall preserve your library. Uninstall using Windows Settings → Apps. Back up and delete the data folder yourself if you want to erase it permanently.

For the portable ZIP, extract first and open Start.cmd. Its library is in .data inside that folder. Copy it when upgrading. Existing ZIP libraries are not migrated automatically.

Link or search limitations

Single public YouTube/Shorts and X videos are supported. Private, live, login-required or platform-blocked videos may fail. You can upload a local copy instead. Describe visible objects and surroundings. This release searches images, not speech, and does not generate summaries. Similarity is not an accuracy percentage.
