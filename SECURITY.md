# Security and privacy

SceneScout is a **single-user loopback application**, not a hosted service.

- The launcher binds to `127.0.0.1`. Host and Origin checks reject external browser origins and unexpected hosts. No CORS wildcard is enabled.
- Imported videos are copied to `.data/videos`; source files remain untouched. The copied file, thumbnails, metadata and vectors persist until removed.
- File IDs are generated by the server. Client filenames are display metadata, never filesystem paths. Thumbnail lookup requires a database record.
- Video uploads are streamed with a 512 MB limit, restricted to MP4/WebM and then decoded. Reference images have an 8 MB limit and a pixel cap.
- Link imports accept only canonical HTTPS YouTube/X video addresses with standard ports and no credentials. Generic extractors, user plugins and browser cookies are disabled. Downloads contact the platform/CDN; source URLs are stored locally. Download subprocesses are cancellable and time/size bounded; temporary files are cleaned up. This is not a general-purpose URL proxy.
- First model use contacts Hugging Face to retrieve a pinned model revision. Queries, videos and reference images are not sent to an inference API. Telemetry is disabled for Hugging Face Hub by the application.
- The optional demo download contacts Blender Foundation. There are no remote scripts, fonts, analytics or UI assets.
- Model weights use safetensors. Remote model code execution (`trust_remote_code`) is not enabled.

Do not expose the server to the internet, place it behind a public tunnel, or use it as a multi-user service. There is no authentication. Host/Origin checks are browser-oriented protections, not an authentication mechanism.

Media parsers process potentially complex files. Import trusted videos and keep the locked dependencies updated. Limits apply to uploaded payloads; reverse proxies and multipart parsers may have separate limits.

For a security report, use GitHub's private vulnerability reporting when enabled. Do not include credentials, private videos or personal data in public issues.
