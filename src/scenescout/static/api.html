SceneScout

A small API for finding a moment.

Local, single-user endpoints. The default server listens at http://127.0.0.1:8765. Your data is processed on this device. These docs work offline.

Download the OpenAPI schema

Import and library

POST /api/imports
JSON {"url":"https://www.youtube.com/watch?v=YE7VzlLtp-4","interval":3}. Accepts HTTPS YouTube videos/Shorts and X/Twitter posts. Returns 202 with a download job ID, or an existing video ID. Only public single videos; no cookies, live streams, playlists or sign-in. Downloads are capped at 720p/512 MB and converted to H.264 MP4 before indexing.
GET /api/imports
Poll the last 20 link imports: queued, downloading, converting, completed, error or paused. Completed records include video_id; poll that video until ready. Restart preserves interrupted jobs for retry.
POST /api/imports/{id}/retry
Retry an error/paused download from the beginning. Returns 202; active/completed jobs return 409.
DELETE /api/imports/{id}
Cancel/dismiss a download job and clean its temporary files. An already imported video remains in the library; remove that video separately.
GET /api/status
Model state, device, model revision, load time and upload limit.
GET /api/videos
Video metadata, status, indexing progress and elapsed time.
POST /api/videos
Multipart file (MP4/WebM, max 512 MB) and interval (1–30 seconds, default 3). Returns HTTP 202 with the video ID. Duplicate content returns the existing ID. Poll the library until status is ready.
DELETE /api/videos/{id}
Remove the imported copy, thumbnails and vectors. Original files remain untouched. Running inference finishes its current frame before cleanup.
POST /api/videos/{id}/resume
Continue a failed or paused index from saved frames. Returns 202; active or ready jobs return 409. Interrupted removals finish on restart.

Search

curl http://127.0.0.1:8765/api/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"a rabbit sitting in the grass","limit":12}'

Text queries accept optional video_id and limit (1–30). The model applies its SearchQuery prompt. Only complete indexes are searched. 

{
  "results": [{
    "id": "videoid-00006",
    "video_id": "videoid",
    "name": "example.mp4",
    "timestamp": 18.0,
    "duration": 30.0,
    "score": 0.7284,
    "thumbnail": "/api/thumbnails/videoid-00006"
  }],
  "elapsed_ms": 58,
  "searched_frames": 10
}

The response above illustrates the shape of an example response. Scores are cosine similarities, not calibrated confidence or percentages. Timecodes are sampled visual moments.

POST /api/search/image
Multipart file (JPEG/PNG/WebP, max 8 MB, max 20 million pixels) and optional video_id. Search for frames resembling a reference image.

Media and timecodes

GET /api/videos/{id}/media
Video bytes with range-request support for browser seeking.
GET /api/videos/{id}/scenes
Up to 80 evenly spaced filmstrip entries with timestamps and thumbnail URLs.
GET /api/thumbnails/{scene_id}
A local JPEG frame thumbnail.

Limits and errors

Videos are limited to two hours and 2,000 sampled frames per import. Increase the sampling interval for longer recordings. Error bodies have a detail field. Indexing errors appear on the video record. Search inference errors return HTTP 503. External hosts and cross-origin requests return HTTP 403.

Audio, transcripts, action recognition and hosted authentication are outside the current release. Do not expose the server to the internet.
